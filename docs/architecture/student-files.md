# Students' own files (`/files`, cloud only)

Every student can add lectures and tutorials for themselves ("הקבצים שלי", `client/src/pages/Files.jsx`; viewer `MyFile.jsx`; strip under a course's lessons/tutorials `components/MyFiles.jsx`): pick any site course (`/api/me/files/courses` lists all of them, `enrolled` marks the student's own), then lectures or tutorials. They are **private and never get AI** – no summary, questions or cards; those exist only for what comes from Moodle or what the owner adds himself on the Mac. `cloud/lib/files.js` keeps them in D1 (`user_files`, `user_file_chunks`; R2 isn't enabled on the account) as base64 chunks of 512 KB: the browser (`client/src/lib/personalFiles.js`) cuts, encodes, decodes and rebuilds the file, so the Function does no per-byte work. Limits in `LIMITS`: 20 MB a file, 100 MB and 60 files a student; types pdf/ppt/pptx/doc/docx (the type is set from the extension, never from the upload). A PDF is read with pdf.js from a blob URL, the rest are downloads. Chunk responses are `no-store` and the service worker skips `/api/me/files/<id>/chunks/` so another account on the same browser never sees them; sign-out clears the in-memory blobs. The files are deleted with the account (`deleteAccount`); they are not part of the published data, of `gate.js`, or of the weekly D1 backup (`/api/admin/backup` exports only users, progress and reports).
